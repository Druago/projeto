# Portfólio Pessoal - Pedro Henrique Alves Ribeiro

Este projeto consiste no desenvolvimento de um portfólio pessoal responsivo, criado com o objetivo de apresentar minhas habilidades, projetos e informações de contato de forma clara, moderna e acessível.

A aplicação foi construída utilizando HTML, CSS e JavaScript puro, sem o uso de frameworks, com foco no aprendizado dos fundamentos do desenvolvimento web. O layout foi estruturado de maneira semântica, facilitando a leitura do código e a manutenção futura.

O projeto conta com diversas funcionalidades interativas, como animações ao rolar a página (scroll reveal), efeito de digitação no texto de apresentação, destaque automático do menu conforme a seção visível e animações suaves em elementos visuais, proporcionando uma melhor experiência ao usuário.

Além disso, foi aplicada responsividade para diferentes tamanhos de tela, garantindo boa visualização tanto em dispositivos móveis quanto em desktops. O design utiliza cores contrastantes e elementos estilizados para melhorar a legibilidade e a estética geral da aplicação.

As seções do portfólio incluem: apresentação inicial (hero), sobre mim, habilidades com descrições interativas, projetos com links externos e área de contato com redes sociais.

Este projeto representa minha evolução como desenvolvedor iniciante e demonstra minha capacidade de estruturar, estilizar e adicionar interatividade a uma aplicação web completa.
